# Troubleshooting: BS5 Speaker Connects but No Sound

1. Check the volume on both the source device AND the speaker itself (the speaker has its own physical
   volume buttons, independent of phone volume).
2. If paired via Bluetooth, confirm the phone/laptop's audio output is actually routed to the BS5 and not
   still playing through the device's internal speaker — this is the most common cause of "silent"
   pairing.
3. If using the 3.5mm aux-in, note that plugging in an aux cable disables Bluetooth audio automatically;
   unplug the aux cable to return to Bluetooth mode.
4. In stereo-pair mode (two BS5 speakers linked), if only one speaker plays audio, re-run the stereo pair
   setup in the NovaVolt Connect app — a dropped stereo link can leave one speaker silently connected
   but muted.
5. If sound is still absent after a factory reset (hold power + volume-down for 8 seconds), this indicates
   a hardware fault and should be escalated for warranty evaluation.
