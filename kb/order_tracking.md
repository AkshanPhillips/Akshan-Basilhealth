# Order Tracking — NovaVolt Electronics

You can track an order from the "My Orders" page using your order ID (format: NV-XXXXXX) or by clicking
the tracking link sent by SMS/email once the order ships.

Order statuses, in order: Placed → Confirmed → Packed → Shipped → Out for Delivery → Delivered. An
order can also show Cancelled or Return Requested.

If tracking shows no movement for more than 2 days, this usually means the shipment is awaiting courier
pickup or is held at a transit hub — it does not necessarily mean the order is lost. Support can escalate
to the courier partner after 2 full business days of no scan updates, but cannot force an earlier delivery.

For exact order status and courier-confirmed details, the support assistant should use the order lookup
tool rather than guessing from the order date alone.
